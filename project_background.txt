I have an embedded system i designed, used for blast wave data gathering for desert test sites. Each module currently contains a solar panel, pi Pico, sd card, GPS, and runs automatically when connected collecting and storing GPS, pressure, temp, and time data. For the next iteration I would like to add Lora radio modules to each in order to send commands (arm, sleep, status, etc) and receive data back tirelessly from whatever was stored on the SD card during a test. Speed does not matter too much as there is lots of time between tests. However, in the desert there is not line of sight between all the modules and the home base server, so I was thinking of creating some protocol for an ad hoc wireless mesh network that will be able to communicate with all the nodes even when some are out of reach or some are offline. My first goal is to create a document detailing the design and algorithm for the network, worrying about implementation later. Please ask any questions in order to get a better understanding of the goals and suggest some routes I could take.
